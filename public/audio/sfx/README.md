# Game sound files

Download generated sound effects here, using the IDs from
[the sound-effect prompts](../../../audio-prompts/game-sounds.md), for example:

- `sfx-ui-confirm.wav`
- `sfx-step-road.wav`
- `sfx-meal.wav`
- `sfx-music-cue.wav`

Prefer WAV, one isolated cue per file. Trim unwanted silence and accompaniment.
No sound-effect playback is wired into the game yet.
